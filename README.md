## What I Learned About GitHub

### Repository
A repository is a place where project files and code are stored.

### Issues
Issues help track tasks, bugs, and improvements in a project.

### Branches
Branches allow developers to work on changes separately from the main project.

### Pull Requests
Pull requests are used to review and merge changes into the main branch.

### Forks
Forks create a personal copy of another repository.

### GitHub Projects
GitHub Projects help organize and manage work using boards and tasks.
